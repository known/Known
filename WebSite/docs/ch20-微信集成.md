# 第20章 微信集成

Known 已经内置微信公众号相关集成能力，适合企业后台常见的扫码绑定、OAuth、模板消息和微信配置管理场景。

---

## 20.1 核心对象

微信相关能力主要位于 `Known/Weixins`：

- `WeixinService`
- `WeixinApi`
- `WeixinExtension`
- `WeChatSetting`

---

## 20.2 主要能力

从 `IWeixinService` 和 `WeixinService` 可确认当前能力包括：

- 获取公众号绑定二维码
- 获取微信系统配置
- 按系统用户获取微信绑定信息
- 检查并关联微信用户
- 保存微信配置

此外，底层还支持：

- OAuth 授权 URL
- AccessToken 获取
- 用户信息读取
- 模板消息发送

---

## 20.3 系统配置入口

`AddKnownWeixin()` 会把 `WeChatSetting` 注入 `UIConfig.SystemTabs`，因此微信配置会进入系统设置页签，而不是孤立页面。

这说明微信能力被当作平台能力统一管理。

---

## 20.4 扫码绑定流程

扫码绑定的典型流程如下：

1. 当前用户请求绑定二维码。
2. 系统根据场景 ID 和用户 ID 生成二维码。
3. 用户在微信中扫码。
4. 系统通过 OpenId 或扫码记录与当前用户建立关联。

`WeixinService.CheckWeixinAsync` 就体现了这种“扫码成功后关联系统账号”的逻辑。

---

## 20.5 适用场景

Known 的微信模块适合：

- 扫码绑定系统账号
- 微信登录或授权辅助
- 审批、消息、通知触达
- 企业内公众号集成

如果需要小程序完整业务前端，通常还需要额外的前端应用配合，但后台服务层仍可复用 Known 的微信能力。

---

## 相关源码文件

- `Known/Weixins/WeixinService.cs`：微信服务接口与实现。
- `Known/Weixins/WeixinApi.cs`：微信 API 封装。
- `Known/Weixins/WeixinExtension.cs`：微信扩展入口。
- `Known/Weixins/WeChatSetting.cs`：微信设置页面组件。
