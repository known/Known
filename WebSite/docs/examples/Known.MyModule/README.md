# Known.MyModule 示例插件

这个目录提供一份可直接参考的 Known 插件样板，对应文档：

- [第28章 从 0 到 1 开发一个插件模块](../../ch28-%E6%8F%92%E4%BB%B6%E6%A8%A1%E5%9D%97%E5%AE%9E%E6%88%98.md)

目录说明：

- `Known.MyModule.csproj`：最小项目文件
- `AppModule.cs`：插件装配入口
- `_Imports.razor`：Razor 导入
- `Entities/`：实体模型
- `Services/`：接口、客户端、服务端实现
- `Pages/`：页面入口
- `wwwroot/`：静态资源
